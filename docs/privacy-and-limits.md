# Data, privacy and preview limits

Data lives in `~/Library/Application Support/Pico`, outside the checkout. There is no telemetry, sign-in, sync, email watcher or remote transcription. Model downloads contact their hosts. OpenToolkit asks GitHub for the latest release shortly after launch and then once a day, so it can show an update badge; nothing about you is sent. Turn this off in Settings › Check for updates automatically. Never commit your library, custom corrections, sounds, captures, credentials or speech environment.

The internal `Pico` data directory and bundle identifiers remain stable across the rename, so existing history, corrections and preferences are reused. The former default “Hey Pico” or “Hey OpenToolkit” becomes “Hey Toolkit”; custom wake phrases are preserved. Quit the old Pico app and stop its speech worker before opening OpenToolkit. The repository is now `Barty-Bart/opentoolkit`.

Stopped dictation is saved as a private recovery recording before recognition, then removed after its transcript commits to history. Failed recordings remain in `Speech/Recovery` within that data folder; there is no automatic retry or expiry yet. This protects processing failures after stopping, not a crash during active capture. Microphone dictation does not require FFmpeg.

English recognition is configured in this preview. Parakeet uses MLX on the GPU; Whisper supports MLX GPU or faster-whisper CPU. Recommendations are hardware heuristics, not performance promises. CPU fallback is optional and cannot recover an OS-killed or hung worker. Exact caret placement and correction detection depend on what the target app exposes through macOS Accessibility.

Basic writing modes format text; Sentence bullets splits sentences without summarizing. Optional AI bullet summaries and AI email drafts use a separate text model through a loopback-only OpenAI-compatible server, such as LM Studio. Configure the server and choose a model in Dictation → Local AI, then select a Writing mode. “Find models” queries only that server when clicked; the app does not scan for installed apps or accounts. AI modes wait until you stop, preserve the original transcript, and cancel sending if rewriting fails. Say “Hey Toolkit”, wait for the cue, then “summarize into bullet points” or “turn this into an email” to use a mode once. Notes summaries, semantic search, sync and a camera overlay for recordings are future work. Wake phrases and sending are off by default. Review the [test results and limitations](testing.md) before relying on this preview. Report reproducible problems through [GitHub Issues](https://github.com/Barty-Bart/opentoolkit/issues), without attaching personal transcripts or recordings.
